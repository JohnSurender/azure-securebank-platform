# Changelog
All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and [SemVer](https://semver.org/).

## [1.0.0] - 2026-10-07
### Added
- Hub-and-spoke network, AKS, ACR, Key Vault, PostgreSQL Flexible Server, Application Gateway WAF v2 and monitoring Terraform modules.
- dev / staging / prod environments with isolated remote state.
- Accounts and Transactions microservices (FastAPI) and static web frontend.
- Helm chart with HPA, PDB, NetworkPolicy and Workload Identity.
- GitHub Actions: Terraform plan/apply with OIDC, app CI, security scanning.
- Architecture diagrams, ADRs, runbooks and PCI DSS control mapping.
